Apache (.htaccess) snippet — place in WordPress root to prefer index.html:

DirectoryIndex index.html index.php

If you create an index.html in the site root it will be served instead of WordPress.

Nginx server block snippet — ensure index order and reload nginx:

server {
  listen 80;
  server_name example.com;
  root /var/www/html; # wordpress root (where wp-config.php lives)
  index index.html index.php;

  location / {
    try_files $uri $uri/ /index.php?$args;
  }

  location ~ \.php$ {
    include fastcgi_params;
    fastcgi_pass unix:/run/php/php-fpm.sock; # adjust to your PHP-FPM socket
    fastcgi_index index.php;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
  }
}

Note: Managed hosts may require control-panel changes; do not overwrite wp-admin.
