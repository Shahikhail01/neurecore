## Pixel Color Legend

| Symbol  | Meaning         | Color     | Usage                               |
| ------- | --------------- | --------- | ----------------------------------- |
| `#`     | Dark background | `#000000` | Main page background                |
| `=`     | Medium gray     | `#404040` | Borders, dividers                   |
| `-`     | Light gray      | `#808080` | Muted elements                      |
| `.`     | White           | `#ffffff` | Cards, text                         |
| `C`     | **CYAN accent** | `#00c3ff` | Search, KPIs, buttons, input fields |
| `R`     | **RED accent**  | `#ff4013` | Alerts, status indicators           |
| `G`     | Green           | `#00c853` | Success indicators                  |
| (space) | Transparent     | -         | Empty areas                         |

## Section Breakdown

### 1. HEADER (Y: 0-30)

- Left: Logo area (#)
- Center: Search bar (medium gray)
- Right: Icons - Bell, User (cyan dots)

### 2. SEARCH AREA (Y: 30-60)

- Large cyan band (C) - input field
- Dark background (#)

### 3. HERO - AI INPUT (Y: 60-120)

- Input field with cyan background
- "Send" button on right (cyan)
- Dark surrounding area

### 4. GREETING (Y: 120-180)

- Main greeting text (white on dark)
- Quick prompt buttons below

### 5. KPI ROW (Y: 180-240)

- 4 KPI tiles (cyan dots + white values)
- Dark card backgrounds

### 6. MAIN CONTENT (Y: 240-470)

- Left: Thin navigation sidebar
- Right: Content cards with:
  - Active Agents (3 cards)
  - Upcoming Tasks (list with red indicators)

## Key Visual Elements

1. **Dark theme** - Black (#000000) background dominates
2. **Cyan accent** - Dominant accent color for interactive elements
3. **White cards** - For KPI tiles and content sections
4. **Red indicators** - For task alerts and status
5. **Layout** - Centered hero, 2-column main content
