## Why G1.1 Is Required

G1 was blocked because the evidence pack contained contradictions that reproduced the exact failures we are reconstructing. Specifically:

## Required Corrections

### A. Idempotency Retention ✅ DONE

**Issue:** Durable business idempotency records expired after 24 hours.

**Fix:** Removed TTL from durable records. Set `expiresAt` to 100 years in the future. Added `purgeOldFailedRecords()` for terminal failed records only (after 30 days).

**Files changed:**
- `src/common/idempotency/command-idempotency.service.ts`

**Verification:** `command-idempotency.service.ts` no longer uses any short TTL. New `farFuture()` helper sets 100-year expiry. `purgeOldFailedRecords()` only deletes FAILED records older than 30 days.

### B. Application Layer Ports ✅ STARTED

**Issue:** Handlers depended directly on `PrismaService`.

**Fix:** Created `IUnitOfWork` port and `PrismaUnitOfWork` adapter. Application code can now depend on the port.

**Files changed:**
- `src/common/ports/transaction.interface.ts` (new) — defines ports
- `src/common/persistence/prisma-unit-of-work.ts` (new) — adapter

**Still TODO:** Refactor each handler to use `IUnitOfWork` instead of `PrismaService` directly. This is multi-step work and should be done incrementally, NOT as a "best effort" claim.
