**Date:** 2026-07-26
**Status:** Pending — requires migration applied

## Why This Document Exists

The previous G1 evidence claimed feature flags were "operational" but never seeded the database or tested the runtime behavior. This document specifies the steps to verify feature flags.

## Step 1: Seed Reconstruction Tenant

After migration is applied:

```sql
-- Create reconstruction tenant
INSERT INTO tenants (id, name, slug, industry, status, "createdAt", "updatedAt")
VALUES (
  'reconstruction-integration-test',
  'Reconstruction Test Tenant',
  'reconstruction-test',
  'accounting',
  'ACTIVE',
  NOW(),
  NOW()
)
ON CONFLICT (id) DO NOTHING;

-- Enable CANONICAL_INITIATION for reconstruction tenant
INSERT INTO tenant_feature_flag_overrides (id, "tenantId", "flagKey", enabled, "setByActorId", version, "createdAt", "updatedAt")
VALUES (
  gen_random_uuid(),
  'reconstruction-integration-test',
  'CANONICAL_INITIATION',
  true,
  'seed-script',
  1,
  NOW(),
  NOW()
)
ON CONFLICT ("tenantId", "flagKey") DO UPDATE SET enabled = true, version = tenant_feature_flag_overrides.version + 1;
```

## Step 2: Verify Seed

```sql
-- Check tenant exists
SELECT * FROM tenants WHERE id = 'reconstruction-integration-test';

-- Check flag override exists
SELECT * FROM tenant_feature_flag_overrides WHERE "tenantId" = 'reconstruction-integration-test';
```

Expected:
- 1 row from tenants table
- 1 row from tenant_feature_flag_overrides with `enabled = true`

## Step 3: Test Runtime Behavior

After seed, verify:

```typescript
// In a test environment:
const flags = new TenantFlagsService(prisma);

const isEnabled = await flags.isEnabled(
  FeatureFlag.CANONICAL_INITIATION,
  'reconstruction-integration-test',
);
expect(isEnabled).toBe(true);

// Other tenants should still be false (default)
const isEnabled2 = await flags.isEnabled(
  FeatureFlag.CANONICAL_INITIATION,
  'other-tenant',
);
expect(isEnabled2).toBe(false);
```

## Step 6: Test Authorization

```typescript
// Verify only TENANT_ADMIN can set overrides
const controller = new TenantFlagsController(flags);
await expect(
  controller.setFlag(
    FeatureFlag.CANONICAL_INITIATION,
    { enabled: true },
    { tenantId: 't1', id: 'unauthorized-user' },
  ),
).rejects.toThrow(); // Roles guard rejects non-admin
```

## Step 7: Test Cache Invalidation

```typescript
// Verify cache invalidates on override
const flags1 = await flags.isEnabled(FeatureFlag.CANONICAL_INITIATION, 't1');
// ... time passes, tenant changes flag
await flags.setOverride(FeatureFlag.CANONICAL_INITIATION, 't1', false, 'admin');
const flags2 = await flags.isEnabled(FeatureFlag.CANONICAL_INITIATION, 't1');
expect(flags2).toBe(false); // Cache was invalidated
```

## Failure Modes to Test

| Failure | Expected Behavior |
|---------|-------------------|
| DB unreachable | All flags return `false` (safe default) |
| Override exists but malformed | Use default `false` |
| Cache stale after override | Invalidation on `setOverride()` |
| Unauthorized user | Roles guard rejects (HTTP 403) |
| Audit log failure | Override still succeeds, error logged |
