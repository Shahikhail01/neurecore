## 2. Restoration Procedure

```bash
# 1. Create target database (as superuser, since neurecore_app can't CREATE DATABASE)
PGPASSWORD=*** psql -U postgres -h 127.0.0.1 -d postgres -c \
  "CREATE DATABASE neurecore_awl_restore_verify OWNER neurecore_app;"

# 2. Set proper schema permissions
PGPASSWORD=*** psql -U postgres -h 127.0.0.1 -d neurecore_awl_restore_verify -c \
  "GRANT ALL ON SCHEMA public TO neurecore_app; ALTER SCHEMA public OWNER TO neurecore_app;"

# 3. Restore from backup
PGPASSWORD=*** psql -U neurecore_app -h 127.0.0.1 -d neurecore_awl_restore_verify \
  -f /opt/neurecore/backups/awl-remediation/neurecore_pre_awl_backup.dump
```
