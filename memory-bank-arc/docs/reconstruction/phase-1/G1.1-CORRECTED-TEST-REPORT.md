## ⚠️ Naming Correction

The previous test report called these "**certification**" tests. That was **incorrect**. The plan (§11) defines certification as:

> "Run certification and correct defects; do not build missing prerequisites"
> "**Golden workflow executions** | 50 runs"
> "**Worker restart** | 10 runs"
> "**Provider/tool failure** | 10 runs"

What was actually run are **unit/harness tests with mocked dependencies**. They verify:
- TypeScript types
- Code shape (files exist, modules wire correctly)
- Pure-function behavior of state machines, circuit breakers, idempotency
- Command pattern plumbing

What they **do not** verify:
- Database transactions commit together
- Real DB uniqueness constraints
- Worker leasing across multiple processes
- Real worker restart recovery
- Real dead-letter behavior
- Migration correctness
- Cross-tenant access at the repository level
